Production WordPress Plugin · Single-File Core

          
goldcrest-market-map.php ([goldcrest_market_map])

          
Ready for wp-content/plugins/goldcrest-market-map/. Enqueues Leaflet and map assets conditionally so WP Go Maps Pro on individual Property CPT pages never conflicts.

        

        

          PHP 8.0+
          
          Download goldcrest-market-map.php
        

      


      

        

          WP Go Maps Pro Safe
          Uses wp_register_* globally and wp_enqueue_* strictly inside the [goldcrest_market_map] shortcode or Elementor widget render call.
        

        

          REST + Mailchimp v3
          POST /wp-json/goldcrest-map/v1/enquiry validates nonce, honeypot, and GDPR consent before dispatching wp_mail() and Mailchimp Buyer Inquiry tag.
        

        

          Google Sheets WP-Cron
          Fetches only the "Map (public)" CSV tab, filters out non-"For sale" statuses, and clamps wider-market coordinates to 2 decimal places.
        

        

          Property CPT Sync
          Queries published "property" CPT posts directly for gold Goldcrest pins with exact coordinates and live permalinks.
